# Neden 0.2.0 preview 1 — validation record

This is an early desktop preview. Installer checks establish build, dependency
loading, and startup on the listed machines; they do not certify every GPU,
audio device, desktop environment, or credential backend.

## macOS Apple silicon

- Package build: [40371186477](https://github.com/HanifCarroll/Neden/actions/runs/40371186477), source `07f7673996bffc1f4e24664eee74f6a152427097`, Qt 6.10.2.
- All 11 CTest suites passed, including decoding a real MPEG-4 fixture.
- DMG integrity and deep strict code-signature checks passed.
- Both bundle version fields are 0.2.0.
- A copied app started with an isolated profile and no Qt/QML/DYLD environment overrides on a separate Apple-silicon Mac; exit 0 in 1.54 seconds.
- The preceding candidate, with identical production C++/QML, also rendered video, Turkish/English subtitles, and the transcript. Instant and native fullscreen transitions, pointer/control idle hiding, and pointer wake passed using generated native events on the Pro's virtual display.
- Audible audio, a physical mouse, and live AI/Keychain interactions were not tested in this package-validation run.
- Signature is ad hoc. Gatekeeper rejects the unnotarized app by default. This is not a Developer ID-signed release.
- SHA-256: `db1044758386c616c47f6696c5154b20953e3986bfa7ee90130a9bc5300d03aa`.
- All 21 corresponding-source archive hashes and notice groups were checked, including the repacked source download.

## Windows x86-64

- Package build: [40376009758](https://github.com/HanifCarroll/Neden/actions/runs/40376009758), source `457c18b`, Qt 6.10.2, MSVC 2022, Windows Server 2022 CI.
- All 11 CTest suites passed, including real MPEG-4 decoding.
- The per-user installer installed successfully, rendered the application’s first frame with an isolated profile and sanitized PATH, returned exit code 0, and uninstalled successfully.
- Release compiler-runtime DLLs are bundled app-locally. Every packaged EXE/DLL was inspected for unresolved dependencies; the unused Qt WebEngine plugin was removed in favor of WebView2.
- Eight pinned upstream archives and 26 MSYS2 dependency-package inventories have matching sources and notices. Source-package signatures were checked against the MSYS2 trusted keyring; source and signature hashes were rechecked after download.
- The installer is unsigned. Physical GPU/audio playback, Windows 10/11 desktop interaction, WebView2 login, and native credential storage were not tested in this run.
- SHA-256: `709adf785b0d6efd780ce5bc0758cf4f10184424da613ec24429585261e686cb`.

## Linux x86-64

- Package build: [40377610662](https://github.com/HanifCarroll/Neden/actions/runs/40377610662), source `a8604aa`, Qt 6.10.2, Ubuntu 24.04 CI.
- All 11 CTest suites passed, including real MPEG-4 decoding.
- The Debian package installed through apt, started the application and rendered its first frame under Xvfb with an isolated profile and build-library overrides removed, then uninstalled successfully.
- Every private ELF uses relative library paths. The dependency scan rejects missing libraries and references into build directories; distribution libraries are declared as versioned package dependencies.
- Chromium’s helper process, resources, and locale files are included for Qt WebView. The unused serial-GPS plugin is excluded. ICU 73.2 is bundled with its matching sources and notices.
- All 12 pinned source archives and notice groups were verified, including after repacking. Hidden upstream notice files are preserved.
- The runner-only smoke check disables Chromium’s sandbox. This setting is not embedded in the package. Physical GPU/audio playback, Wayland, embedded browser login, native credential storage, and other distributions were not tested.
- SHA-256: `ec28f3be07eac6529019650acb3d2315b16b113f48e8efa5bed0d113127fdc96`.

## Publication

The package build commits above identify the exact CI inputs. Subsequent changes
in the release tag concern packaging, validation, documentation, and the website;
production C++/QML matches the tested macOS candidate. Corresponding-source
archives and `SHA256SUMS` accompany the installers. The website’s download
manifest links to these versioned assets, not transient CI artifacts.
